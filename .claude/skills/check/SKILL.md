---
name: check
description: Zuggleのlintと全テストを回し、落ちたものを直して通るまで繰り返す。変更を入れた後・push前・「テストして」「確認して」と言われたときに使う。
---

1. `tools/dev.sh check` を実行する（Godotがなければ自動で入れる。lint → 3つのテストを並列、30秒台）。
   1つだけ回すなら `tools/dev.sh test hitlab` のように名前を渡す。
2. 失敗したら、出力の `FAIL` の行と `at:` の場所から原因を読む。
   - テストを消す・緩める・飛ばすことで通してはいけない。仕様が変わったときだけ、README の仕様とあわせてテストを直す。
   - 並列で時間に依存するテスト（ヒットストップ）が1回だけ落ちたときは、その1本を単独で回して確かめる。単独でも落ちたら本物の失敗。
3. 直したらもう一度 `tools/dev.sh check`。全部 PASS になるまで繰り返す。
4. 挙動を変えたら README の該当節を更新し、リリースするなら `tools/dev.sh bump <新しいversion/name>` で版を上げる。
