# Zuggle 仕様書（パルクール版）

版：0.6.0-p2（2026-10-04 P2の前半：着地・手応え・勢いの取りこぼし）
旧版の「パルクール斬撃アクション」から、**一人称パルクールゲーム**へ方針を変えた。戦闘（ナイフ）はいったん外し、手触りに全振りする。

---

## 1. 一言で

**走る勢いを、左手と右手で地形に引っかけて、途切れさせずにつなぐ一人称パルクール。**

## 2. 柱（判断に迷ったらここへ戻る）

1. **勢いは財産**：どの動作に入っても、どの動作から出ても、水平速度を落とさない。落とすのはプレイヤーが止まりたいときだけ。
2. **手は意思**：左手＝掴む、右手＝押す。ボタンを押した手が、画面の中で実際にその場所へ伸びて掴む・つく。何をしたかが手で分かる。
3. **ゆるい入力、正確な結果**：先行入力・コヨーテタイム・押しっぱなしでの自動キャッチで、タイミングの厳しさではなくルート選びで上手さが出るようにする。
4. **酔わない一人称**：カメラの傾き・揺れは控えめにし、すべて調整パネルで0にできる。

## 3. エンジン

**Godot 4.6（GDScript）を続ける。** UE5には乗り換えない。

| 観点 | Godot（いま） | UE5 |
| --- | --- | --- |
| 手触りの試行 | 調整パネルで全値をその場で変えられる。自動テストがヘッドレスで数秒 | Blueprint/C++のビルド待ちが長い |
| 既存資産 | 移動・壁走り・テスト・APKの自動リリースがそろっている | 作り直し |
| Android | APK 27MB前後（ナイフのテクスチャ込み） | 空のプロジェクトでも約150MB（インストール後）になる報告がある。最適化しても50MB前後 |
| 強み | 小さく速い | Motion Matching等、本物の全身アニメーションを載せるとき |

本物の脚のモデルとアニメーションを入れる段階で、全身IKやモーションマッチングが要るほど重くなったら見直す（P4の前に判断）。

## 4. 操作

| 操作 | パッド（Xbox配置） | キーボード・マウス |
| --- | --- | --- |
| 移動 | 左スティック | WASD |
| 視点 | 右スティック | マウス / 矢印キー |
| ジャンプ / 壁ジャンプ | A | Space |
| しゃがみ / スライディング | B | C / 左Ctrl |
| **左手：掴む** | LB | Q / 右クリック |
| **右手：押す** | RB | E / 左クリック |
| 調整パネル | Back（View） | F1 |

ナイフの操作（X / J：攻撃、Y / F：ナイフ回し）は保管中。本編には出ない。

## 5. 動きの一覧

### 5.1 基本（足）

| 動き | 入り方 | 中身 | 出方 |
| --- | --- | --- | --- |
| 走り | スティック | 最高8 m/s。加速60・減速50 m/s² | ― |
| ジャンプ | A | 初速6.5 m/s、重力16、落下時×1.6、離すと上昇×0.5（小ジャンプ）。コヨーテ0.10秒、先行入力0.12秒 | ― |
| 勢いの持ち越し | 最高速度を超えて着地し、走り続ける | 超えた分は4 m/s²でしか減らない（12 m/sなら1秒で8へ） | 入力を離すと通常の減速 |
| スライディング | 5 m/s以上で走ってB（空中で押す・押しっぱなしで着地でもよい） | +2.5 m/s（加速だけでは12 m/sまで）。4 m/s²で減速。45度/秒だけ曲がれる。目線0.8m下がり、体の高さ1.0m | Bを離す（最短0.35秒）、3.5 m/s未満、ジャンプ（速さはそのまま空中へ） |
| スライドホップ | スライディング→ジャンプ→空中でB→着地 | 着地した瞬間にまたスライディング。加速は1秒に1回まで（Titanfall 2のスライドホップと同じ考え方） | ― |
| しゃがみ歩き | 遅いときにB | 3 m/s。高さ1.0m | 離す。天井が低ければ立たない |
| **受け身** | 高所（落下の速さ13.5 m/s以上＝約3.6m）からの着地で、着地の0.3秒前〜0.08秒後にB。押しっぱなしでもよい（スライドホップと同じ押し方） | 0.45秒転がる。水平の速さを保つ（真下に落ちても4 m/sで前へ）。低い段差を下りても転がり続ける | 時間切れ（Bを押したままならスライディングへ）、A（速さはそのまま空中へ） |
| **強い着地** | 同じ高さからBなしで着地 | 水平の速さが3割になり、0.4秒は体が低く遅い。跳べない | 時間切れ。宙に出たら終わる |

2mの台から跳び降りた程度（約3.3m）では強い着地にならない。Mirror's Edgeの「長い落下の着地の直前に押すと前転して勢いを保つ」に合わせた。

### 5.2 壁

| 動き | 入り方 | 中身 | 出方 |
| --- | --- | --- | --- |
| 壁走り | 空中で4 m/s以上、壁に60度以内で寄る（ボタンなし） | 進入速度を壁沿いに保つ。上向き2 m/s、重力×0.25、上限1.75秒。逆へ倒すと折り返す | 壁の端・反対へ倒す・着地・時間切れ |
| 壁ジャンプ | 壁走り中にA（離れてコヨーテ0.10秒以内も可） | 壁から5 m/s、上へ6 m/s。壁沿いの勢いは保つ | ― |
| **壁登り** | 壁へ正面から跳び込み、壁へ向けてスティックを倒している | 上へ6.5 m/s、重力×0.55、上限0.75秒（約2.4m登る）。同じ壁は着地まで1回。登る前の水平の速さは着地まで覚えておく | 登り切れず落ちる / 上端を越えると前へ押し出して乗る（登る前の速さ×0.85） / A で壁ジャンプ / 左手で縁掴み（登る前の速さを持ち出す） |

### 5.3 左手＝掴む（LB）

押した瞬間に届くものがあれば掴む。**押しっぱなしにしておけば、届いた瞬間に掴む**（先行入力0.15秒）。

| アクション | 条件 | 中身 | 出口 |
| --- | --- | --- | --- |
| **縁掴み（マントル）** | 前（壁走り・壁登り中は壁の側も）0.7m以内に壁、その上端が足元から0.6〜2.3m、上に立てる空きがある | 左手が縁を掴み、引き上げ（前半）→前へ乗る（後半）。0.32秒（高さで0.6〜1.3倍） | 入る前の水平速度（壁登りからなら登る前の速さ）×0.85（最低3 m/s）を前へ。登り切る直前のAで、上に乗った瞬間に跳ぶ（マントルジャンプ） |
| **ポール回り** | 縦のポール（`pole` グループ）の中心から1.2m以内 | 半径0.7mで回る。速さは入る前の速さ（壁登りからなら登る前の速さ。最低5 m/s）。視点も回る分だけ回る。重力×0.15でゆっくり下がる。上限1.2秒 | 左手を離す / A / 時間切れ。接線の向きへ +1.5 m/s、上へ3 m/s（Aなら6.5） |
| 空振り | 何もない | 手を前へ伸ばして戻す | ― |

### 5.4 右手＝押す（RB）

| アクション | 条件 | 中身 | 出口 |
| --- | --- | --- | --- |
| **ボールト** | 前0.9m以内に高さ0.3〜1.3mの障害物、越えた先（奥行き1.6m未満）か上（それ以上）に体が入る | 右手を上面について弧を描いて越える。時間は距離÷速さ（0.15〜0.3秒） | 入る前の速さ +1.5 m/s（最低4 m/s）。奥が深ければ上に乗る。終わり際のAで、越えた瞬間に跳ぶ（ボールトジャンプ） |
| **壁押し** | 横か前の0.8m以内に壁（壁走り・壁登り中はその壁） | 壁から6 m/s、上へ3 m/s。壁沿いの勢いは保つ。同じ壁は着地まで1回 | ― |
| 空振り | 何もない | 手を前へ伸ばして戻す | ― |

左右の役割の違い：**壁ジャンプは上へ逃げる、壁押しは横へ切り返す**。壁走り→壁押し→向かいの壁で壁走り、が速いルートになるよう地形を作る。

縁掴み・ボールトの出口のジャンプは、動作の終わり0.12秒（ジャンプの先行入力）以内に押したものだけ。動作に入る前に押したAは持ち越さない。
柱1（勢いは財産）と柱3（ゆるい入力）から、動作の途中で押したAを捨てずに次の動きへつなぐ。

### 5.5 手応え（音と振動）

柱2（手は意思）を、見た目に加えて音とパッドの振動でも返す。音は素材を持たず、起動時にその場で作る（`scripts/parkour_feel.gd`）。

| 場面 | 音 | 振動 |
| --- | --- | --- |
| 縁・ポールを掴む | 金属の手のカチッ＋低いドッ | 弱・強とも軽く |
| ボールト・壁押しで手をつく | こもったペタッ | 弱モーターを短く |
| 着地 | 低いドン（落ちた速さで大きく） | 弱モーターを短く |
| 強い着地 | 同じ音を低く大きく | 強モーターを強く0.2秒 |
| 受け身 | ドッ＋転がるゴロッ | 弱・強とも中くらい |
| スライディング | 床を擦るシャーッ | 弱モーターを短く |
| 空振り | ヒュッ（小さく） | なし |

音量（`sfx_volume`）と振動（`rumble_strength`）は調整パネルで0にできる。

## 6. 見た目

### 6.1 手（両手）

- メカの手（Meshy製）を両手に使う。左手は右手を左右反転したもの
- 構え：画面の下の端。走ると左右交互に腕を振る（速いほど大きく）。空中では少し広げて上げる。スライディング中は画面の外へ
- アクション：0.07秒で目標へ伸ばし、0.18秒で戻す。指は「軽く握る / 開く / 平ら / 握る」をなめらかに切り替える
  - 縁掴み：縁の上に手のひらを下にして握る
  - ポール：ポールを握ったまま回る
  - ボールト：上面に平手
  - 壁押し：壁に平手、指は上
- 壁走り中は壁の側の手を少し前の壁に添える。壁登り中は両手で交互に壁を叩く
- 受け身では両手の平手を前の床につき、強い着地では指を開いて床を突く

### 6.2 脚（仮）

- 箱で作った仮の脚（太もも・すね・靴）。本物のモデルが来たら差し替える（`scripts/legs_view.gd` の箱を置き換える）
- 走り：速さに合わせて振る。空中：片脚を畳む。スライディング：前の脚を伸ばして画面に見せ、後ろの脚を畳む。壁走り・壁登り：速く回す。縁掴み：膝を上げる。ボールト：横へ流す。受け身：膝を抱える

### 6.3 カメラ

- 視野角90度、目の高さ1.65m、画面中央の点
- 壁走りで6度、スライディングで3度傾ける。頭の揺れ0.015m。すべて0でオフにできる
- 受け身で視点を25度前へうなずかせて戻す（強い着地はその6割）。一回転はさせない（酔う）。0でオフ
- 強い着地で少しだけ画面を揺らす（0.3、0でオフ）

## 9. 調整の進め方

1. 調整パネル（F1 / Back）で1項目だけ動かす
2. 倍と半分を試し、良い側へ詰める
3. 「値をコピー」で今の値をこの下の改善ログに貼る
4. 決めた値は `scripts/tuning.gd` の初期値に書き戻す
